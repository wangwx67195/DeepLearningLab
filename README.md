# DeepLearningLab

个人深度学习代码学习实验室。

## Environment

Python:
3.11

Conda:
dllab

PyTorch:
2.10.0

CUDA:
12.8


## Goal

从 Python/PyTorch 基础开始，
独立实现主流深度学习模型核心算法。

目标：

- nanoGPT
- Transformer
- Diffusion
- Flow Matching
- VAE
- GAN
- 3D deep learning models


## Learning Rule

本项目采用：

理解 -> 手写 -> 调试 -> 重构

而不是：

复制 -> 粘贴 -> 运行
